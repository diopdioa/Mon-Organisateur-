MON ORGANISEUR — VERSION FINALE

Le fichier index.html contient l'application complète.
Pour une vraie installation PWA sur iPhone, les fichiers doivent être servis depuis
une adresse HTTPS (par exemple un hébergement web). Sur iPhone : ouvrir l'adresse
dans Safari, Partager, Ajouter à l'écran d'accueil.

Les rappels individuels peuvent demander l'autorisation de notifications.
La notification fiable en arrière-plan sur iPhone dépend du mode d'installation
PWA et de la version d'iOS; le rappel dans cette version fonctionne quand
l'application est ouverte, et utilise les notifications lorsque le navigateur/PWA
les autorise.
